# 🌐 ashura.site — Personal Portfolio

> A personal developer portfolio, hand-built from scratch.
> Live at **[ashura.site](https://ashura.site)**

---

## 📸 Overview

**ashura.site** is a personal portfolio showcasing projects, certificates, internship experience, and hackathon achievements — built and maintained as I grow as a developer. New "occasion" pages get added as new milestones are reached.

Built with vanilla HTML, CSS, and JavaScript — no frontend frameworks, just clean fundamentals.

---

## 🗂️ Site Structure

```
ashura-site/
├── index.html            # Home / landing page
├── about/                 # About me
├── occasions/             # Milestone pages (certificates, internships, hackathons)
├── certificates/          # Certificate assets
├── Pics/                  # Images
├── Videos/                # Video assets
├── Styles/                # Stylesheets
├── script/                # JavaScript
└── sitemap.xml / robots.txt
```

## 🧰 Tech Stack

**Frontend**
- HTML5, CSS3, Vanilla JavaScript
- Hand-rolled, no frontend frameworks

**Hosting & Infrastructure**
- [GitHub Pages](https://pages.github.com/) — static hosting
- [Cloudflare](https://cloudflare.com) — DNS, CDN, and edge security (WAF, TLS termination, security headers via Worker)

**Dev Environment**
- Kali Linux
- Git for version control

---

## 🔒 Security

This site has gone through a full security hardening pass:

- **TLS/SSL:** A+ rated configuration (modern protocols only, strong ciphers, forward secrecy)
- **Security headers:** Content-Security-Policy, Strict-Transport-Security (HSTS), X-Frame-Options, X-Content-Type-Options, Permissions-Policy, Referrer-Policy
- **WAF:** Cloudflare-managed, in front of GitHub Pages origin
- **Origin protection:** Real hosting origin abstracted behind Cloudflare's proxy
